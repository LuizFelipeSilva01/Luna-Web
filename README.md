Para podermos administrar nosso aplicativo Luna, desenvolvemos um site web com o intuito de acompanhar a evolução do projeto, usando um dashboard com informações a cerca dos usuários do app. Esse site é direcionado apenas aos devs e admins do projeto, tendo seu acesso feito diretamente pelo Firebase e podendo acessar a página administrativa por um login na área de apresentação do App, onde, além dessa página, temos também duas páginas focadas em atrair novos usuários e apresentar nosso projeto a eles.
